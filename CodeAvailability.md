# Code availability

Custom scripts used for manuscript-level analyses, workflow documentation, figure generation, supplementary-table construction, and numeric consistency auditing are provided in this repository.

The repository includes scripts and audit records for:

- sample-level RNA-seq and ATAC-seq quality control;
- low-abundance filtering;
- DESeq2 likelihood-ratio testing;
- Tau and SPM tissue-specificity analyses;
- UROPA-based peak-to-gene association;
- RNA-ATAC quantitative coupling;
- same-tissue permutation analysis;
- promoter-first and TSS-distance analyses;
- motif-background construction and motif-support summarization;
- candidate-module construction;
- figure generation and supplementary-table source locking;
- manuscript numeric consistency auditing.
