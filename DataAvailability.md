# Data availability

All raw sequencing data analyzed in this study are publicly available through NCBI GEO/SRA.

RNA-seq data:

- GEO accession: GSE158412
- BioProject: PRJNA665193

ATAC-seq data:

- GEO accession: GSE158414
- BioProject: PRJNA665194

GEO SuperSeries:

- GSE158430

The experimental organism is Sus scrofa, NCBI Taxonomy ID 9823. The reference assembly used for reanalysis was Sscrofa11.1, NCBI assembly GCF_000003025.6, with Ensembl release 115 gene annotation.

Large raw sequencing files, alignment files, and large intermediate files are not redistributed in this repository.
