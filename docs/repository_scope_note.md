# Repository scope note

This repository documents the manuscript-level computational workflow and provides the custom scripts used to generate, summarize, audit, and package the reported analyses.

Some scripts contain local absolute paths from the original analysis server. These paths are retained for provenance and traceability. Users reproducing the workflow should adapt these paths to their own local directory structure.

Large raw sequencing files, BAM files, bigWig files, and large intermediate matrices are not redistributed in this repository.
